# Release Notes: Full

## Anime4K Video Converter 1.0.0

Portable Windows build with bundled FFmpeg tools.

### Includes

- Java runtime
- Application launcher
- Bundled `ffmpeg`
- Bundled `ffprobe`
- Bundled Anime4K shader presets

### Highlights

- Batch folder scanning for supported video files
- Anime4K preset-based processing pipeline
- Per-file and overall progress indicators
- Saved paths and settings between launches
- Auto-scan of the saved input folder on startup
- Portable package with no separate Java installation required

### Notes

- Distribute the whole portable folder, not only the `.exe`
- Supported video encoders: `h264_nvenc`, `h264_amf`, `h264_qsv`, `libx264`
- Requires an FFmpeg build with `libplacebo`
- Third-party notices and license notes are included in the repository

### Download

Recommended asset:

- `Anime4KVideoApp` portable folder or archive
